# Achievements Roadmap

Criteria last checked: 2026-10-05

GitHub publishes no official criteria list. Tiers below are community-documented and may change.

Sources:
- https://github.com/Schweinepriester/github-profile-achievements
- https://redirect.github.com/orgs/community/discussions/38187
- https://docs.github.com/en/pull-requests/committing-changes-to-your-project/creating-and-editing-commits/creating-a-commit-with-multiple-authors

Already unlocked: Pull Shark x2, YOLO, Quickdraw.
Out of scope: Arctic Code Vault, Mars 2020 (not earnable); Heart On Your Sleeve, Open Sourcerer (disabled); staff-only badges.

Ground rules: one account, no bots or unattended scripts, no trivial or spam PRs, human pace. The owner performs every public action.

## 1. Pull Shark x3 — 128 merged PRs (tiers 2 / 16 / 128 / 1024)
- [x] Tier 2 (16 PRs)
- [ ] Tier 3: 128 merged PRs. Estimate 45 on 2026-10-05, 83 to go (see tracker.md)
- [ ] Every PR is a focused change a maintainer or I would actually want
- [ ] Flagship repo built through feature-branch PRs (Workstream A)
- [ ] Contribution PRs to projects I use, linked to issues (Workstream B)

## 2. Pair Extraordinaire — co-authored commit in a merged PR (next tiers 10 / 24 / 48 PRs)
- [ ] PARKED: no partner has agreed yet
- [ ] A real person agrees and gives the email to use
- [ ] Real shared work; commit message ends with a blank line then `Co-authored-by: Name <email>`
- [ ] PR merged

## 3. Galaxy Brain — accepted Discussion answers (tiers 2 / 8 / 16 / 32)
- [ ] Not earnable in GitHub's own Community Discussions since Feb 2024; use other projects' Discussions
- [ ] Shortlist repos in my stack with Discussions Q&A enabled
- [ ] Each answer tested by me, edited by me, posted by me
- [ ] Never ask anyone to accept an answer
- [ ] 2 accepted answers

## 4. Starstruck — a repo I created reaches 16 stars (then 128 / 512 / 4096)
- [ ] Flagship repo chosen and scaffolded
- [ ] README, LICENSE, tests/CI, CONTRIBUTING, issue templates, topics, first release
- [ ] "good first issue" labels
- [ ] Honest, on-topic promotion only; no bulk star requests, no star-for-star swaps
- [ ] 16 stars from real people

## 5. Public Sponsor — sponsor an open-source contributor via GitHub Sponsors
- [ ] Shortlist maintainers of tools I depend on
- [ ] I choose maintainer, amount, one-time vs monthly, and visibility (public)
- [ ] I complete payment myself
